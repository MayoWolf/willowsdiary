# Willow’s Diary

A one-page eveningwear site for Willow’s Diary. The collection overview covers the fabrics and size range supplied by the brand. The editorial photographs are collection inspiration.

## Preview locally

Run `python3 -m http.server 8000 --directory public` from the repository and open [localhost:8000](http://localhost:8000).

## Publish on Netlify

Import this repository into Netlify. The checked-in `netlify.toml` sets the publish directory to `public`. The static site needs no build command, dependencies or environment variables.

For a manual upload, drag the `public` folder into [Netlify Drop](https://app.netlify.com/drop).
