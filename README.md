# Willow’s Diary

A one-page lookbook for Willow’s Diary’s evening minis in black lace, leopard print and bronze sequins. The collection uses sample dress names and generated concept imagery.

## Preview locally

Run `python3 -m http.server 8000 --directory public` from the repository and open [localhost:8000](http://localhost:8000).

## Publish on Netlify

Import this repository into Netlify. The checked-in `netlify.toml` sets the publish directory to `public`. The site is static and needs no build command, dependencies or environment variables.

For a manual upload, drag the `public` folder into [Netlify Drop](https://app.netlify.com/drop). It already contains the deployable site.
