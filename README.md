# Willow’s Diary

A static storefront preview for Willow’s Diary. It contains a four-slot collection, dedicated style pages, a measurement guide, contact information, and policy sections. Concept photography and style names are retained only as preview content.

Before enabling commerce, replace concepts with approved photos and final product data (prices, sizes, fabric and care), and supply confirmed brand contact, social destinations, published store policies and a real checkout with verified payment methods. The gallery layout supports adding approved product angles.

## Preview locally

Run \`python3 -m http.server 8000 --directory public\` and open http://localhost:8000/.

## Publish on Netlify

The production publish directory is \`public\`, configured in \`netlify.toml\`. No build command or environment variables are required.
